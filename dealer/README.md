# DealerEasy — сайт, склад и заявки для автосалонов

Веб-приложение для небольших автосалонов в ЮАР, по образцу CarWashEasy. Машину добавляют один раз, и она сразу появляется:

- на собственном быстром сайте салона;
- в каталоге Facebook/Instagram;
- на площадках (AutoTrader, Cars.co.za, Gumtree, AutoMart, SearchMyRide), когда подключение для салона согласовано.

Проданные машины везде снимаются сами. Заявки покупателей приходят в приложение и на почту, отвечать можно в WhatsApp в одно касание.

Интерфейс, лендинг и сайты салонов на английском. Работает как мультитенантный сервис: салон регистрируется сам и видит только свои данные.

Название меняется через `APP_NAME` (по умолчанию `DealerEasy`).

## Что умеет

| Для салона (`/app`) | Для вас (`/admin`) |
|---|---|
| **Склад:** в продаже, черновики, проданные; стоимость стока, дни на складе, машины старше 60 дней, прибыль за месяц | Лендинг с ценой и FAQ, **живое демо** без регистрации (стирается через 24 ч) |
| **Карточка машины:** скан лицензионного диска (марка, модель, цвет, кузов, VIN, номер); подсказки марок, моделей и комплектаций; фото сжимаются на телефоне и грузятся по одному; главное фото и порядок; опции; «Write it for me» пишет описание | Все салоны: триал и оплата, +1/+12 месяцев, пауза, сброс пароля, «Open app» |
| **Только для салона:** номер, VIN, номер двигателя, закупка и вложения, прибыль при этой цене | **Готовые сайты для салонов, которые ещё не зарегистрировались:** с примерами машин, выбором темы и кнопкой «I like this look» → передача владельцу |
| **Заявки:** с сайта (вопрос по машине, тест-драйв, кредит, продажа или trade-in с фото, сообщение) и записанные вручную; статусы New → Contacted → Deal done / No deal; заметки; ответ в WhatsApp готовым текстом | **Подключения площадок:** запросы салонов, ссылка на фид для площадки, «Connected» |
| **Площадки:** Facebook/Instagram подключается самим салоном; для остальных кнопка «Connect»; у каждой машины галочки «где рекламировать»; «Copy ad» и «Save photos», чтобы выложить вручную | Свой домен салона (`www.joesmotors.co.za`), HTTPS выпускается сам |
| **Сайт:** 5 тем; логотип; слоган, «о нас», «почему мы»; текст под каждой машиной; кредитный калькулятор; контакты и часы | **Письма вам:** регистрации, запросы на площадки и сводка в 22:00 |

## Сайт салона

Адрес: `https://<домен сервиса>/site/<салон>/`. Если у салона есть свой домен, сайт открывается на нём (см. ниже).

Страницы:

- **Главная:** быстрый поиск (марка, цена), типы кузова, свежие машины, «почему мы», кредит, trade-in, «о нас», недавно проданные.
- **Каталог** с фильтрами (марка, модель, кузов, цена, год, пробег, КПП, топливо), сортировкой и страницами. Работает и без JavaScript.
- **Машина:**
  - галерея со свайпом, миниатюрами и полноэкранным режимом;
  - цена и «было», платёж в месяц;
  - кнопки WhatsApp (с текстом про эту машину), «Book a test drive», «Call»;
  - характеристики, опции, описание, форма заявки, похожие машины;
  - разметка schema.org `Car`, Open Graph (превью в WhatsApp и соцсетях).
- **Кредит:** калькулятор (депозит, срок, ставка, balloon; работает и без JavaScript) и анкета без ID и банковских данных.
- **Продать авто:** форма и до 6 фото.
- **Контакты**, **Privacy** (POPIA), `sitemap.xml`, `robots.txt`.

Сайт быстрый:

- HTML собирается на сервере;
- JavaScript около 8 КБ;
- шрифты свои, без внешних CDN, анимаций нет;
- каждое фото хранится в WebP 400/800/1200/1600, и браузер берёт размер под экран;
- первое фото грузится с высоким приоритетом, остальные лениво, а до загрузки на месте фото виден его средний цвет;
- фото кэшируются на год: имя файла — хеш содержимого;
- Caddy отдаёт фото прямо с диска;
- данные о месте съёмки из фото удаляются.

После окончания подписки сайт и фиды работают ещё 7 дней. Потом на сайте остаются только контакты, а машины уходят с площадок.

## Автопубликация на площадки

Проверено 18.10.2026:

| Площадка | Как подключается |
|---|---|
| **Facebook / Instagram** | **Сам салон, без договоров.** В Meta Commerce Manager создаётся каталог *Vehicles* с фидом по расписанию, туда вставляется адрес фида из приложения (`/feeds/<ключ>/facebook.csv`, формат Meta Vehicle catalog). Каталог бесплатный, салон платит только за рекламу (Automotive inventory ads). Нужны город, провинция и координаты (Settings → Business). Бесплатных объявлений салонов на Marketplace Facebook больше нет. |
| **AutoTrader** | Автоматически принимает сток только от одобренных поставщиков, публичного API нет. Нужно договариваться с AutoTrader. Пока договора нет, салон выкладывает машину вручную в AutoTrader Connect: «Copy ad» и «Save photos» в карточке машины. |
| **Cars.co.za** | Через интеграторов (VMG и др.), спецификация не публичная. Контакт отдела продаж: 011 450 2450, info@cars.co.za. |
| **Gumtree** | Через подключённых поставщиков фидов. Своя интеграция — разработка на их стороне и контракт минимум на 6 месяцев (stores@gumtree.co.za). Салону нужен Gumtree for Business (от R599/мес). |
| **AutoMart / Junk Mail, SearchMyRide** | Дилерские аккаунты через отдел продаж. SearchMyRide принимает фиды дилерских систем. |
| **Google** | Vehicle ads в ЮАР недоступны, а отдельная выдача машин в поиске закрыта в 2025 году. Сайт индексируется обычным образом: `sitemap.xml`, у каждой машины своя страница. |

**Как это устроено:**

1. Салон нажимает «Connect» → у вас в `/admin` появляется запрос, и сразу приходит письмо.
2. Вы договариваетесь с площадкой: у салона там аккаунт, у вас договор поставщика фида.
3. Отдаёте площадке адрес фида салона (`/feeds/<ключ>/autotrader.xml` и т. п.) и жмёте «Connected».

Пока площадка не попросила свой формат, фид — наш общий XML: все машины в продаже, с фото, ценой и характеристиками. Есть также `stock.json` и `stock.csv`.

В фид попадают только машины в продаже, с ценой и фото, у которых эта площадка не снята. Каждую выгрузку площадки видно: «last picked up 2 h ago».

## Библиотека марок и комплектаций

- Марки и модели — стартовый список (около 50 марок, продаваемых в ЮАР, включая снятые модели, которые часто встречаются б/у): `app/catalog.py`.
- Комплектации **накапливаются**. Каждая сохранённая машина реального салона попадает в общий справочник (`variants`) вместе с кузовом, топливом, КПП, приводом, двигателем, дверьми и местами. У следующего салона они появляются в подсказках и заполняют характеристики.
- Полный справочник вариантов ЮАР — коды M&M от TransUnion, по лицензии. Подключать, когда понадобятся кредит и оценка.

## Стек

Python 3.12 · Flask · SQLite · Pillow (фото) · серверные шаблоны + `app.js` (приложение) и `site.js` (сайты салонов) · без внешних CDN.
Продакшн: Docker + Caddy (бесплатный HTTPS от Let's Encrypt, в том числе для доменов салонов).

## Запуск локально

```bash
cd dealer
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
ADMIN_PASSWORD=admin flask --app app run --debug    # http://127.0.0.1:5000
pytest                                               # тесты
```

База и фото — в `./data`.

## Деплой (Google Cloud, как у мойки)

Можно на той же виртуалке, что и мойка, но с другим доменом: тогда нужен один общий Caddy на 80/443 (см. «Две программы на одной виртуалке»). Проще — отдельная `e2-small`.

1. **Виртуалка, IP, firewall:** как в README мойки, имена `dealer-ip` и `dealer`.
2. **Домен:** A-запись `dealereasy.co.za → IP`.
3. **Установка:**
   ```bash
   git clone https://github.com/vbuleiko/octane.git && cd octane/dealer
   bash deploy/setup-vm.sh      # Docker, rsync, .env со случайным SECRET_KEY
   nano .env                    # DOMAIN, ADMIN_PASSWORD, SUPPORT_WHATSAPP, NOTIFY_EMAIL, SMTP_*
   sudo docker compose up -d --build
   ```
4. **Обновление:** `bash deploy/update.sh`.
5. **Бэкапы:** `bash deploy/backup.sh` — база (14 дней) и фото (только новые). Каждую ночь через `crontab -e`; с `BACKUP_BUCKET=gs://...` копия уходит и в Cloud Storage.

**Две программы на одной виртуалке.** Каждый `docker compose` поднимает свой Caddy на 80/443, поэтому вместе они не запустятся. Решение: оставить один Caddy (например, мойки) и добавить в его Caddyfile блок для `dealereasy.co.za` с `reverse_proxy` на контейнер салонов, подключив оба compose к общей docker-сети. Если понадобится — сделаю.

## Свой домен салона

1. Салон в DNS своего домена добавляет `CNAME www → dealereasy.co.za` (для голого домена — A-запись на IP сервера).
2. Вы в `/admin` вписываете `www.joesmotors.co.za` и жмёте **Save**.
3. При первом заходе Caddy сам получит сертификат: он спрашивает приложение (`/tls-check`) и выдаёт сертификаты только для доменов, сохранённых в `/admin`.

На этом домене: `/` — сайт салона, `/app` — его приложение (вход `/login` только для владельца). Регистрация, демо и `/admin` там не открываются. В фидах площадок и в Google ссылки на машины ведут на домен салона.

## Сайт для салона, который ещё не зарегистрировался

1. `/admin` → *Dealers that haven't signed up*: по строке `Название | Адрес | Город | WhatsApp | ссылка Google Maps`. Сайт сразу готов, с машинами-примерами (подписаны «Example»).
2. Чтобы сайт выглядел «их», жмёте **Open app** и добавляете несколько их настоящих машин: примеры исчезают, как только появляется хоть одна своя.
3. Отправляете владельцу ссылку (в админке есть «send the link on WhatsApp»). Владелец пробует темы и жмёт **I like this look** → вам приходит WhatsApp.
4. Владелец согласился: вписываете его email и тему → **Hand over**. Появится пароль, бесплатный пилот на `PILOT_DAYS` дней начнётся с этого дня.

Заявки покупателей с такого сайта (если кто-то напишет) приходят вам на `NOTIFY_EMAIL`: хороший повод позвонить салону.

## Настройки (.env)

| Переменная | Что это |
|---|---|
| `DOMAIN` | домен сервиса (Caddy/HTTPS) |
| `SECRET_KEY` | длинная случайная строка |
| `ADMIN_PASSWORD` | пароль `/admin`; пусто = админка выключена |
| `SUPPORT_WHATSAPP`, `SUPPORT_EMAIL` | ваши контакты (кнопки «Subscribe», «I like this look», поддержка) |
| `APP_NAME` | название продукта, по умолчанию `DealerEasy` |
| `PRICE_MONTHLY`, `PRICE_YEARLY` | цены на лендинге, по умолчанию `R499` и `R4,990` — **черновые, решите сами** |
| `TRIAL_DAYS`, `PILOT_DAYS` | триал 30 дней, пилот 60 |
| `THEME` | тема по умолчанию: `carbon`, `volt`, `midnight`, `noir`, `classic` |
| `NOTIFY_EMAIL`, `SMTP_*`, `MAIL_FROM` | почта, как у мойки. Без `SMTP_PASSWORD` писем нет, в том числе заявок салонам — **для работы почта обязательна** |
| `COOKIE_SECURE` | `1` на HTTPS |
