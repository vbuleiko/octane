# Octane Auto: сайт и админка

Новый сайт автосалона [Octane Auto](https://www.octaneauto.co.za) (Montague Gardens, Cape Town) в стиле **Pit Lane**: чёрный фон, фирменный оранжевый `#F48222`, шахматный мотив оранжево-серого пола из их студии, курсивный шрифт Saira. Логотип не менялся.

Внутри:

- **Публичный сайт**:
  - главная: «машина недели», сетка авто с фильтром по кузову, кредитный калькулятор, мастерская, контакты;
  - шоурум с поиском, фильтрами, сортировкой и пагинацией;
  - страница авто: галерея с полноэкранным режимом и свайпами, характеристики, опции, описание, кредит, заявка, похожие авто;
  - страницы «Финансы», «Мастерская», «Продать авто» (с фото), «О нас», «Контакты» (карта), POPI;
  - SEO: метаданные, Open Graph, schema.org `Car`, `sitemap.xml`, `robots.txt`.
- **Админка** (`/admin`):
  - дашборд;
  - склад: поиск, статусы, массовые действия, «на главную»;
  - карточка авто: загрузка фото с drag-and-drop и выбором обложки, опции чипами, «Write from specs», живое превью карточки;
  - входящие заявки со статусами и заметками;
  - настройки: контакты, часы, кредитные ставки, «машина недели», WhatsApp;
  - синхронизация с VMG.
- **Данные**: при первом запуске загружаются все 39 реальных авто с фото, опциями и описаниями (`data/vmg-snapshot.json`).

## Стек

Next.js 16 (App Router, Server Actions) · React 19 · TypeScript · Tailwind CSS 4 · SQLite (better-sqlite3 + Drizzle ORM) · sharp (обработка фото) · jose/bcrypt (сессии админки).

## Запуск локально

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env           # задать AUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm run db:seed                # 39 авто из снимка + первый админ
npm run dev                    # http://localhost:3000, админка: /admin
```

`npm run db:seed -- --live` берёт сток прямо из живого фида VMG, а не из снимка.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` / `build` / `start` | разработка / сборка / продакшен-сервер |
| `npm run typecheck` | проверка TypeScript |
| `npm run db:seed` | наполнение базы (повторный запуск ничего не дублирует) |
| `npm run vmg:snapshot` | обновить `data/vmg-snapshot.json` из живого фида |
| `npm run admin:create -- email пароль "Имя"` | создать админа или сбросить пароль |
| `npm run db:generate` | новая миграция после правок `src/lib/db/schema.ts` |

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `STORAGE_DIR` | папка для базы SQLite и загруженных фото (по умолчанию `./storage`, на сервере должна быть постоянной) |
| `AUTH_SECRET` | секрет для подписи сессий админки (`openssl rand -base64 32`), в продакшене обязателен |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | первый админ, создаётся при `db:seed` |
| `SITE_URL` | публичный адрес сайта (sitemap, Open Graph, schema.org) |
| `SMTP_URL`, `SMTP_FROM` | по желанию: письма о новых заявках на email из настроек, например `smtps://user:pass@smtp.example.com:465` |

## Откуда берутся авто

Сейчас сток клиента ведётся в DMS **VMG Software**; их WordPress-сайт берёт данные из JSON-фида. В новом сайте возможны оба варианта, решение не заблокировано:

1. **Админка — единственный источник.** Авто заводятся и правятся в `/admin`, VMG можно отключить.
2. **Синхронизация с VMG.** Кнопка «Sync now» в настройках (или `npm run db:seed -- --live`):
   - добавляет новые авто со всеми фото;
   - обновляет цену и пробег;
   - по желанию помечает проданными пропавшие из фида.

   Описания, опции, «на главной» и авто, добавленные вручную, синхронизация не трогает. Для автоматического запуска можно повесить cron.

## Деплой

Нужен Node-хостинг с постоянным диском (VPS, Railway, Render, Fly.io с volume):

```bash
npm ci && npm run build && npm run db:seed && npm start   # порт 3000, перед ним nginx/caddy с HTTPS
```

Vercel в текущем виде не подходит: SQLite и загруженные фото требуют постоянного диска. Под Vercel нужно перевести базу на Turso/Postgres, а фото на S3/R2.

## Структура

```
src/app/(site)/        публичные страницы
src/app/admin/         вход и админка; server actions в actions.ts
src/app/actions/       обработка форм сайта (заявки)
src/components/site/   компоненты сайта (карточка авто, галерея, калькулятор, формы)
src/components/admin/  компоненты админки (форма авто, фото, таблица склада)
src/lib/               база, запросы, авторизация, загрузки, импорт VMG, настройки
data/vmg-snapshot.json снимок реального стока для первого запуска
docs/research.md       аудит старого сайта
```

## Что осталось от клиента

- Вектор логотипа (SVG/AI). Сейчас используется PNG 241 px из старого сайта, поэтому крупнее примерно 120 px он не показывается.
- Номер WhatsApp. Включается в настройках админки.
- Проверка текста POPI-политики юристом клиента.
